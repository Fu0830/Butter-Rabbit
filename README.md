# 黄油兔饼家族 · 家族树（单页 HTML）

游戏风格家谱页：世代家谱树、成对卡片、点击查看个人信息、缩放拖拽、五条属性拉杆。**一个 `index.html` 就是全部**，直接放 GitHub Pages 即可访问。

在线预览：https://fu0830.github.io/Butter-Rabbit/

## 页面里能做什么

| 操作 | 效果 |
| --- | --- |
| 点击人物头像 | 弹出「个人信息」：智力 / 体质 / 魅力 / 人品 / 快乐 五条**可拖动拉杆**（0–160，实时改数值与配色）、收入支出、职业熟练度、学历与就学经历 |
| 滚轮 / 双指捏合 / 左侧滑杆 | 缩放家谱（0.14×–1.9×） |
| 拖拽空白处 | 平移 |
| 双击 | 快速放大 |
| 左下定位按钮 | 回到全族视图 |
| 齿轮 | 时间流速（0–8×）、是否显示每人速率、导入 Excel、重置时间 |
| 铅笔 / 家族名 | 改家族名 |
| 红色播放键 | 暂停 / 继续时间，跨年年龄 +1 |

## 用 Excel 改人物

改 `黄油兔饼家族-人物表.xlsx` 的《人物表》工作表：

- `ID` 唯一；`配偶ID`、`父亲`、`母亲` 填对方 ID 来表达关系（配偶要互填）
- `世代`、`校验` 是公式，自动算，不用手填
- 加人＝插一行；减人＝删整行，并检查有没有别人还引用这个 ID
- 改完保存 → 网页齿轮 →「导入 Excel」→ 选文件，家谱按关系重建

> 导入时才从 CDN 加载 SheetJS（Apache-2.0），页面本身无其他依赖；离线时手改 `PEOPLE` 也可以。

## 部署

1. 新建仓库，把 `index.html` 放根目录（原仓库：`Fu0830/Butter-Rabbit`）
2. Settings → Pages → Source 选 `Deploy from a branch`，Branch `main` / `(root)`
3. 约 1 分钟后 `https://<用户名>.github.io/Butter-Rabbit/`

## 说明

- 视觉按游戏截图复刻：心/钱/日期条、家族名胶囊、夫妻卡片、蓝色个人信息弹窗、缩放滑杆与定位按钮。
- 头像全部是参数化 SVG，改发色/发型/肤色/衣服色即可换人，不会裂图。
- 拉杆只改页面内存数值，刷新回到表里的值；要永久保存就改 Excel 再导入。
- 字体走 CDN（SIL OFL），断网回落系统字体，页面仍可用。
